TNWISE 2026 Backend Lead

VAANI — Voice Assistant for Government Services

A multilingual web app allowing citizens to access 12 government services in 8 Indian languages — Tamil, Hindi, Telugu, Malayalam, Kannada, Bengali, Marathi, and Gujarati — via voice or text. Complete Python Flask backend with intent detection, MyMemory translation API, JWT authentication, session tokens, feedback system, and offline caching for low-connectivity areas.

CoolCity TN — Urban Heat Island Simulator

AI-powered climate simulation platform for Tamil Nadu cities (Chennai, Coimbatore, Hosur, Madurai). Canvas-based ward heat map with real-time colour gradients, green intervention simulator with temperature projections, bilingual Tamil/English toggle, dark/light theme, Web Speech API TTS, and citizen hotspot reporting — all in a single self-contained HTML file with zero dependencies.
